# Mucugê - Chapada Diamantina

Site informativo sobre a cidade de Mucugê (BA), desenvolvido como atividade prática na ETEC-SP, utilizando HTML, CSS e o framework W3.CSS.

## 🚀 Tecnologias utilizadas

- HTML5
- CSS3
- W3.CSS Framework
- Google Fonts
- Font Awesome (ícones)

## 📌 Funcionalidades

- Layout responsivo
- Cards com imagens e efeito hover
- Seções de informações e pontos turísticos
- Uso de grid do W3.CSS
- Personalização com CSS próprio

## 📷 Imagens

As imagens utilizadas são meramente ilustrativas, obtidas de fonte externa (Férias Tur).
